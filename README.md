# 🔥 Basal Metabolic Rate Calculator

> 📱 A **mobile Android application developed in Java** to calculate Basal Metabolic Rate (BMR) in a simple, fast, and intuitive way.

---

## 📱 About the Project

The **Basal Metabolic Rate Calculator** is a mobile application developed for **Android devices**, using **Java**.

The application allows users to enter basic information such as **age, weight, height, and gender**, and then calculates an estimated **Basal Metabolic Rate (BMR)**.

BMR represents an estimate of the amount of energy the body needs to maintain its basic vital functions while at rest.

This project was developed to put into practice concepts related to **Java programming, mobile development, programming logic, and Android user interface development**.

---

## 🚀 Features

* 🔥 Basal Metabolic Rate (BMR) calculation
* 👤 Gender selection
* ⚖️ Weight input
* 📏 Height input
* 🎂 Age input
* 📊 BMR result displayed in kcal/day
* 📱 Mobile-friendly Android interface
* ⚡ Fast and easy calculation
* 🔄 Option to perform a new calculation

---

## 🧮 How It Works

The application collects the information entered by the user and uses a metabolic formula to estimate their BMR.

**Information used:**

```text
Gender
Age
Weight
Height
```

After entering the required information, the application processes the data and displays the estimated result in **kilocalories per day (kcal/day)**.

> ⚠️ The result is only an estimate and should not be considered a substitute for professional medical or nutritional advice.
